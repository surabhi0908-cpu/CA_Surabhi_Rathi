UPLOAD TO GITHUB PAGES FROM YOUR PHONE

1) Unzip in your Files app. You get: index.html, surabhi-rathi.vcf and an "assets" folder.
2) github.com -> New repository -> name it (e.g. surabhi-personal-profile) -> Public -> Create.
3) Add file -> Upload files. Upload index.html and surabhi-rathi.vcf.
   Then upload the 5 photos inside "assets" (sunset.jpg, surabhi-portrait.jpg, reading.jpg, yoga.jpg, mountains.jpg).
   They must end up inside a folder called assets (if your phone can't upload folders,
   type "assets/" before the file name when GitHub lets you name the file, or upload the
   folder from a desktop/Safari "Request Desktop Site").
4) Commit changes.
5) Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
Surabhi Rathi website
6) After a minute, open the live link. Tap Call, Email, LinkedIn, Instagram and Save contact to test.
